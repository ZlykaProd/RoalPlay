# ROYAL PLAY — demo

Внутри:
- адаптивный интерфейс казино/arcade;
- Roulette, Blackjack, Slots и Dice на виртуальные RP;
- баланс и простая игровая логика;
- премиальный маркетплейс с домами, яхтой и автомобилем;
- фильтры каталога и модальные окна.

Важно: это демонстрационный фронтенд. Реальные деньги, платежи, ставки и оформление сделок не подключены.
